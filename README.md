# BSA08_UseCase — Сценарии использования

Варианты использования системы записи в барбершоп: управление графиком, бронирование услуги и просмотр расписания. Описания ролей, предусловий, основных и альтернативных потоков.

Учебные работы по бизнес- и системному анализу. В репозитории представлены результаты выполнения; исходные условия заданий и учебные материалы не включены.
